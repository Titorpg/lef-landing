# LEF — Brand Kit para landing page

Este kit contiene todo lo necesario para construir la landing de LEF (Learn English Fluently) respetando su identidad de marca ya definida.

## Cómo usar esto en Claude Code

1. Lee primero **`BRAND_GUIDELINES.md`** — define colores, tipografía, logo, tono de voz y principios de layout. Es la fuente de verdad para cualquier decisión visual.
2. Lee **`LEF_CONTENT.md`** — es el copy real y verificado del programa. Úsalo para escribir los textos de la landing sin inventar información sobre metodología, oferta o evaluación.
3. Usa los archivos de **`assets/`** directamente como imágenes/logos del proyecto (ya vienen optimizados y con fondo transparente donde aplica).
4. Abre **`reference-brand-guide.html`** y **`reference-handbook.html`** en el navegador para ver el sistema de diseño ya aplicado — son el ejemplo más fiel de cómo debe verse y sentirse la landing (tipografía grande, poco espacio muerto, fondo oscuro solo en portada/cierre, fotos a color con borde sutil).

## Prioridad si algo no está definido

Si una decisión de diseño no está cubierta en `BRAND_GUIDELINES.md`, replicar el criterio visible en `reference-handbook.html` antes que usar un patrón genérico.

## Restricciones importantes

- No usar colores fuera de la escala de grises + azul definidos.
- No usar el logo a color, con sombras o distorsionado.
- El azul nunca va en el logo ni en títulos principales.
- Sin precios ni lenguaje de urgencia/promoción agresiva.
